# Vision — Portfolio Nicolas Von Muhlinen

## What it is

A personal portfolio website for Nicolas Von Muhlinen, a Fullstack developer based in Argentina. It showcases professional experience, projects, and technical skills to potential clients and employers.

## Who it's for

- **Primary**: Tech recruiters and hiring managers evaluating senior/mid-level fullstack candidates
- **Secondary**: Potential freelance clients looking for web development services
- **Tertiary**: Other developers for networking and reference

## Problem it solves

Replaces a generic LinkedIn/CV with an interactive, branded experience that communicates technical depth, design sensibility, and personality — things a flat document can't.

## Core goals

1. **First impression in under 5 seconds** — name, role, availability status, and a polished UI that signals competence
2. **Showcase real work** — projects with screenshots, tech stacks, and live/repo links
3. **Human presence** — profile photo, personal intro, location, and social links make it feel like a person, not a template
4. **Performance and accessibility** — fast load, semantic HTML, i18n (ES/EN), reduced-motion support
5. **Continuous improvement** — structured animation/UX roadmap to keep evolving the experience

## Long-term direction

- Add case studies with problem/solution narratives for key projects
- Integrate a blog or writing section for technical articles
- Expand i18n to additional languages if targeting new markets
- Automate project data from GitHub activity
