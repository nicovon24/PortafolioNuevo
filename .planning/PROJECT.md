# PortfolioNicoNvo

Portfolio personal de Nicolas Von Muhlinen. El proyecto usa una base visual inspirada en PortfolioBase, pero con estructura propia, contenido migrado desde PortfolioNicoViejo y una implementacion limpia en Next.js.

## Objetivo

Mostrar perfil profesional, experiencia, stack tecnico y proyectos relevantes de Nico con una experiencia moderna, animada, responsive y preparada para evolucionar.

- Tono: tecnico, claro, moderno y personal
